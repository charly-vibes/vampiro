# Vampiro

> Cross-language Rust CLI (v0.2.0) for checking whether code composes correctly at call and module boundaries. Supports Python, Clojure, Julia, and Rust via tree-sitter frontends.

## What It Does

Cross-language Rust CLI (v0.3.1) that checks whether the pieces of a codebase actually compose. Uses tree-sitter frontends for Python, Clojure, Julia, and Rust to emit a shared Composition IR (CIR) with per-slot data-flow edges. Composition seam analysis achieves ~99.8% precision on clean baselines.

### Seam Axes

| Axis | Question |
|---|---|
| **composition** | Does the produced structural shape match what the caller accepts? |
| **modularity** | Does the edge respect the target module's declared interface? |
| **optionality** | Are structurally interchangeable implementations lawfully interchangeable? |
| **robustness** | Are effects, retries, fallbacks, and resource obligations handled completely? |

## Key Commands

```
vampiro check     # Check source files for composition, modularity, and robustness breaks
```
